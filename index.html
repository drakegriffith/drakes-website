Welcome to my website.

Welcome

This is my personal website. I made it myself. I write things here instead of posting them on a platform that will change its font in two years.

It looks like 2010 because 2010 loaded instantly and nobody had to accept cookies to read a paragraph. There is no framework here. There is one CSS file and a bash script. The whole site weighs less than the average tracking pixel budget and it will still open in fifteen years.

Go to the blog to read the posts.

Two things worth knowing

The Pledge. I am building a blog hub where anyone can publish and nobody is allowed to use AI. I read every submission myself, because a model should never get a vote here. I build agent systems for a living, which is why I want one place that is only people.

MCP. This 2010 website speaks Model Context Protocol. Agents kept scraping it badly, so now there is a real endpoint, a feed.json, and a server your assistant can talk to. The most machine-readable site I own is also the one that renders fine in Netscape. Those were never opposites.
