# drakes-website MCP server

An MCP server for a website that looks like it was made in 2010. Both facts are load-bearing.

Zero dependencies, one file, Node 18+. JSON-RPC 2.0 over stdio.

## Install

```bash
git clone https://github.com/drakegriffith/drakes-website
claude mcp add drakes-website -- node ./drakes-website/mcp/server.js
```

Or in a config file:

```json
{
  "mcpServers": {
    "drakes-website": {
      "command": "node",
      "args": ["/absolute/path/to/drakes-website/mcp/server.js"]
    }
  }
}
```

## Tools

| Tool | Args | Returns |
| --- | --- | --- |
| `list_posts` | `limit?` | Every post, newest first: title, date, word count, URL |
| `get_post` | `slug` | Full plain text of one post (slug or title fragment) |
| `search_posts` | `query`, `limit?` | Ranked keyword hits with the surrounding sentence |
| `get_pledge` | — | The No-AI Pledge, so your agent knows the house rules |

## Data source

Resolved in this order:

1. `FEED_URL` env var
2. `../feed.json` in the clone (offline, instant)
3. `https://drakegriffith.github.io/drakes-website/feed.json`

`feed.json` is regenerated by `build-feed.py` at the repo root, which runs automatically
inside `new-post.sh`. It is a plain script. Nothing in this repo calls a model.

## Test it without an agent

```bash
printf '%s\n' \

  | node mcp/server.js
```
